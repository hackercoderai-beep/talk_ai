# Talk AI
It's a AI-powered video call platform that lets users create and interact with customizable AI agents in real-time video meetings. Users can configure agents with specific personalities and instructions, start meetings with them, and have natural voice-based conversations for use cases such as tutoring, coaching, interviews, or sales assistance. After each meeting, the platform provides an AI-generated summary, video recording, searchable transcript, and an interactive chat interface for asking questions about the conversation.
